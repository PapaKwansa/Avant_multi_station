# Exploratory Larry COMSOL strain-to-pressure inversion

This is an **add-only** observed-data extension to the tested pressure-superposition baseline.
It reads the *actual* processed COMSOL strain time series, not the synthetic
strain observations generated by `run_pressure_superposition_checks.py`.
It estimates **equivalent pressure changes conditional on fixed geometry and
mechanics**; it does not infer permeability or establish spatial pressure truth.

## Input files

- **Edit only** `configs/pressure_superposition/larry_observed_001.json` for this experiment.
- `benchmark_config` references the immutable prepared Larry configuration:
  `configs/pressure_superposition/larry_network_001/configuration.json`.
- `strain_file` points to the original processed COMSOL observations:
  `datasets/comsol/1darcy/processed/verification_transient/strain_unique_time.csv`.
- The benchmark config points to `stations_analytical_depth.csv`, which already
  contains the verified **positive-downward analytical depths**. Do not convert
  these depths again. Original COMSOL metadata remains unchanged.
- `fine_splits` controls the mechanical tiles. `pressure_models` controls the
  independent pressure zones; every coarse split must divide the matching fine
  split. `uniform` and `four_zone` are model names, not hard-coded options.
- `holdout_stations` are excluded from inversion but used for predictions.
- `time_indices` selects **zero-based row indices**, excluding row 0 because
  row 0 defines the pressure/strain reference. Or set `all_times: true` and
  `time_indices: null` to invert all subsequent times.
- `prior_mean_pa`, `prior_sd_pa`, and `assumed_error_std_ns` are **assumptions**,
  not established uncertainties for COMSOL. Test alternatives.

## Run from repository root (Windows Anaconda)

```bat
python -m pytest -q
python scripts/inversion/run_pressure_inversion_comsol.py --config configs/pressure_superposition/larry_observed_001.json --output-dir results/pressure_superposition/larry_observed_001
```

Use a **new output directory** for every run. The script refuses to overwrite.

## Interpretation

- The model subtracts the **first strain observation** from each later strain
  observation, and estimates the **pressure change relative to that first time**.
  It does not infer absolute pore pressure.
- Each time is inverted **independently**. The same reference observation is
  reused at all times, so there is cross-time correlation not accounted for
  in this exploratory runner. Do not treat intervals across times as joint
  confidence/credible bands.
- `assumed_error_std_ns` is an assumed standard deviation for each original
  strain observation. The script uses `sqrt(2)` times that value for the
  difference of two independent samples; this does not capture numerical
  discrepancy or correlated errors.
- The prior is independent Gaussian across pressure zones and permits signed
  changes. Its scale materially affects uncertainty and inferred heterogeneity.
- Geometry and elastic properties are fixed at the Larry transient benchmark;
  there is no hydraulic flow equation or permeability estimation.
- The holdout RMSE compares **strain**, not recovered pressure. Better fit from
  a larger model does not establish real pressure heterogeneity.
- The COMSOL pressure-monitor series is **not used as inversion forcing** here.
  It can be examined separately as a pointwise reference, but does not supply
  spatial pressure truth for all zones.

## Outputs

- `summary.json`: training and held-out strain RMSE per pressure model.
- `provenance.json`: source hashes, Git commit, assumptions, and caveats.
- `<model>_pressure_posterior.csv`: zone means, SDs, marginal Gaussian 95% intervals.
- `<model>_channel_predictions.csv`: observed, predicted, residual strain changes
  for each selected time/channel and training/holdout flag.
- `<model>_matrix_and_covariance.npz`: design matrix and full pressure covariance
  at each selected time (same under fixed Gaussian assumptions).
- `<model>_pressure_history.png`: conditional pressure estimates and intervals.
- `<model>_strain_parity.png`: training and held-out strain parity.

This is an **exploratory inverse calculation**. Before scientific interpretation,
compare prior/noise assumptions, inspect existing no-fit COMSOL validation
residuals, test alternative pressure representations, and obtain spatial COMSOL
pressure fields for independent verification where possible.
